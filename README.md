## 01. Christmas Tree

![Christmas Tree Pattern](screenshots/Screenshot%202026-10-26%20223206.png)
**Logic:**
- Created 3 pyramids of increasing heights using separate methods.
- Added extra leading spaces to align the pyramid sections.
- Used nested loops to print spaces and stars.
- Star formula: `2 * i - 1`.
- Created the trunk using fixed spaces and a rectangular star pattern.

**Dry Run:** Stars per row → `1, 3, 5, 7, 9...`

**Complexity:** Time: `O(n²)` | Auxiliary Space: `O(1)`

**Key takeaway:** Combine multiple patterns, adjust leading spaces for alignment, and add a trunk to build a larger design.
